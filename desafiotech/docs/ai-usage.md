# Uso de Inteligência Artificial

# Ferramentas Utilizadas

Durante o desenvolvimento utilizei ferramentas de IA como apoio técnico e organizacional.

As ferramentas foram usadas para:

- acelerar tarefas repetitivas
- revisar ideias
- organizar backlog
- revisar arquitetura
- auxiliar debugging
- apoiar documentação

---

# Como a IA Foi Utilizada

A IA auxiliou em:

- geração de boilerplate
- sugestões arquiteturais
- organização dos cards
- troubleshooting
- estruturação da documentação
- revisão de código
- organização de testes
- exemplos de payload

# Validação Humana

Todo código gerado foi:

- revisado
- adaptado
- executado
- validado manualmente

A aplicação foi testada localmente durante o desenvolvimento.

# Decisões Tomadas Manualmente

As decisões abaixo foram tomadas considerando o escopo do desafio:

- uso de Redpanda
- uso de Flyway
- uso de Strategy Pattern
- uso de idempotência
- organização em camadas
- priorização do fluxo principal

# Limitações Encontradas

Durante o desenvolvimento surgiram dificuldades relacionadas a:

- Docker Desktop
- Testcontainers
- configuração do Redpanda
- listeners Kafka
- portas locais
- diferenças entre host local e rede Docker

Esses problemas foram solucionados progressivamente durante o desenvolvimento.
